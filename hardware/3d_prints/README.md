# 3D-Printable Parts

Each part is provided in two formats:

| Part | STL | STEP |
|---|---|---|
| Base mount | `base_mount.stl` | `base_mount.step` |
| Pitch mount | `pitch_mount.stl` | `pitch_mount.step` |
| Camera mount | `camera_mount.stl` | `camera_mount.step` |
| Passive pitch pivot | `pitch_pivot.stl` | `pitch_pivot.step` |

Use the STL files for slicing and printing. Use the STEP files when dimensions,
mounting features, or other mechanical details need to be inspected or edited.
